# Project 2: Heart Disease Exploratory Data Analysis (EDA)

## Objective
The objective of this project is to enhance practical learning of exploratory data analysis (EDA)
by working with a publicly available clinical dataset.

## Dataset
This project uses a public heart disease dataset containing demographic information,
clinical measurements, and diagnostic indicators related to cardiovascular disease.

## Project Description
This project focuses on practicing the full EDA workflow, including:
- Data loading and inspection
- Understanding variable types and meanings
- Descriptive statistics
- Visual exploration of distributions
- Basic descriptive comparison between groups

The aim is to understand the structure and patterns in the data before any statistical
testing or modeling.

## Learning Outcomes
Through this project, I practiced:
- Interpreting summary statistics (mean, median, quartiles)
- Identifying distribution shapes (normal, skewed)
- Understanding the use of visual tools such as histograms and boxplots
- Performing simple descriptive group comparisons without inferential claims
